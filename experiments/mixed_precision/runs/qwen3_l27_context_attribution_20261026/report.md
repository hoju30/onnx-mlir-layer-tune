## 首頁回答

### 1. 情境依賴是否存在？——在同一批文章上確認存在

D = NLL(p8e1) − NLL(f16)，負值代表 p8e1 較好，nat/token；95% CI 來自文章 bootstrap 20000 次。

| 背景（其他 195 個投影哪些依 A 量化，其餘 FP32） | D | 95% CI |
|---|---|---|
| U：全 FP32 | +0.0005 | [−0.0014, +0.0023] |
| P：L0–26 全部依 A | −0.0025 | [−0.0046, −0.0005] |
| F：全部依 A（含 L27 自己的 q/k/v/o/gate/up；F + f16 即原 knee A） | **−0.0070** | [−0.0091, −0.0049] |

- **主要比較 C1 = D_F − D_U = −0.0075 [−0.0095, −0.0054]**：情境依賴確認。
- 這和前三輪跨批次看到的順序一致（+0.0006 → +0.0047 → +0.0085），現在是在同一批文章上直接比較。
- **拆成兩段**：D_P − D_U = −0.0030 [−0.0050, −0.0011]；D_F − D_P = −0.0045 [−0.0061, −0.0028]。
  - 前面各層（L0–26）與 L27 自己的其他投影都有貢獻。

### 2. 是哪些層造成的？——不是單一層，是分散的、累積的交互

單組背景相對 U 的變化（D_g − D_U，5 組 Holm 校正）：

| 組 | 量化的投影數 | D_g − D_U [95% CI] | Holm p |
|---|---|---|---|
| own：L27 的 q/k/v/o/gate/up | 6 | −0.0018 [−0.0036, +0.0001] | 0.28 |
| early：L0–13 全部 | 98 | −0.0010 [−0.0027, +0.0007] | 0.68 |
| late：L14–26 全部 | 91 | −0.0010 [−0.0030, +0.0009] | 0.68 |
| attn：L0–26 的 q/k/v/o | 108 | +0.0009 [−0.0006, +0.0022] | 0.68 |
| **ffn：L0–26 的 gate/up/down** | 81 | **−0.0027** [−0.0046, −0.0008] | **0.03** |

**單組結果**
- 只有「L0–26 的 FFN 都量化」這一組單獨就顯著產生部分效應。
- attention 單獨量化完全沒有效果。
- 前半（L0–13）或後半（L14–26）單獨都不顯著。

**加成性**
- 完整效應 −0.0075，減去 own + early + late 各自效應的和，還剩 −0.0037 [−0.0066, −0.0007]。
- 減去 own + attn + ffn 的和，剩 −0.0038 [−0.0066, −0.0010]。
- 也就是說，各組單獨的效應加起來只有完整效應的一半左右，另一半只在多組一起量化時才出現。
- L27 自己的投影單獨只有 −0.0018，但在前面各層已量化時加進來卻帶來 −0.0045，也是交互。

**結論**
- 沒有哪一層是來源。
- 效應隨「其他地方累積的量化誤差」而放大，其中 FFN 的貢獻最明顯。

### 3. 為什麼？——兩個槽位都翻轉；機制只到線索層級

L27 Down 的 p8e1 只套在 input x 或只套在 output y（其餘為 f16）：

| | 全 FP32 背景（U） | 全量化背景（F） | 背景改變量（F − U） |
|---|---|---|---|
| 只在 x | −0.0028 [−0.0041, −0.0015] | −0.0098 [−0.0114, −0.0082] | −0.0070 [−0.0085, −0.0054] |
| 只在 y | **+0.0017** [+0.0002, +0.0033]（有害） | **−0.0051** [−0.0069, −0.0033]（有利） | −0.0068 [−0.0082, −0.0054] |
| x 與 y 交互 | +0.0016 | +0.0079 | — |

**槽位行為**
- 全 FP32 時：x 的好處被 y 的壞處與交互抵消，總效應約 0。這重現了 reversal diag 的結論。
- 全量化背景下：x 的好處變成約 3.5 倍，y 從有害翻成有利。兩者部分重疊（交互 +0.0079），淨效應 −0.0070。

**描述性統計**（f16 設定下的 L27 Down，全部窗口）

| 背景 | input \|x\| 最大 | output \|y\| 最大 | \|y\| > 4096（p8e1 maxpos）的元素 |
|---|---|---|---|
| U | 1749 | 5302 | 249 |
| F | 1963 | 5800 | 263 |

- 超過 4096 的元素中，約 98% 在 position 0。
- 在量化背景下，L27 的極端值較大。

**線索（未證明）**
- 其他層（尤其 FFN）的量化誤差累積後，放大了 L27 Down 在 position 0 附近的極端值。
- p8e1 的粗量化與截斷（maxpos 4096）在這些位置剛好抵銷了一部分累積的誤差，形成「誤差補償」。
- 本輪沒有按位置拆分效應，所以「作用在 position 0」仍是假說。

**對 pipeline 的意義**
- BC 只在 FP32 情境下估每個節點的成本，本質上看不到這種「其他層量化後才出現」的補償效應。
- 這是單節點加成型 criterion 的結構限制，不是調整某一項公式就能修的。

## 控制（全部通過）

- **重現前輪**：在 L27 native confirm 的 128 篇文章上，F + f16、F + p8e1 與前輪 PyTorch A／C 逐窗口完全相同（C − A = −0.00834）。
