# Qwen3-0.6B L27 Down：條件化、帶正負號的一階評分

日期：2026-10-26。
- 腳本：`run_qwen3_conditional_signed_score.py`（sha256 `eaf7e35ee710…`，見 amendment）。
- 計畫：`plan.json`／`plan.md`（19:27 寫入；一筆 amendment）。
- 規格：`reports/qwen3_conditional_signed_score_prompt_20261026.md`。

**範圍**
- 只做 L27 Down；目標權重固定為原 knee A 的 INT8。
- 後端是 GPU LMReplay，不是 native。
- 沒有修改正式 BC、搜尋、配置、量化器或 native pipeline。

**分數**
- S_b,G(f) = Σ_G g_b·(z_f − z_f16)。
- z_f 是由原始（input QDQ 之前）的 x，經完整 input 與 output QDQ 得到的輸出。
- g_b 是同背景在 f16 輸出處的 summed-CE 梯度，只經過 final norm 與 head，不需要 STE。
- 每個背景、每個 calibration 窗口只取一次梯度。
- 分數在原 10 個 calibration 窗口上建立並凍結；新文章只用來量真值。

**單位與符號**
- S 與真值 D 都是相對 f16 的 nat/token 貢獻，負值代表比 f16 有利。
- 新文章做文章 bootstrap 20000 次。

### 3. 其他格式：小擾動有效，大擾動失敗

All 位置的方向判讀；三個背景結果一致，數值以 F 背景為例：

| 格式 | 凍結 S | 新文章真值 | 方向 | 備註 |
|---|---|---|---|---|
| p8e1 | −0.020 | −0.010 | ✔（U／F／W 全對） | 小擾動 |
| p6e1 | −0.088 | +0.066 | **✘**（U／F／W 全錯） | calibration 真值 +0.080 已錯 |
| p4e1 | −0.023 | +0.233 | **✘**（F、W 錯；U 的 S +0.004 碰巧對） | calibration 已錯 |
| int8 | −0.145 | +0.368 | **✘**（全錯） | calibration 已錯 |
| int6 | +0.134 | +0.930 | ✔ | 方向對，量級低估約 7 倍 |
| int4 | +0.173 | +0.640 | ✔ | 方向對，量級低估 |
| bf16、fp32 | 約 0 | 約 0 | 未定 | 與 f16 幾乎無差 |

**同位元配對**（INT − Posit）
- int8–p8e1：三個背景都錯。S 認為 int8 較好，實測 p8e1 好 0.38。
- int6–p6e1、int4–p4e1：都對。

**判讀**
- 大擾動的失敗在 calibration 上就已經出現：S 為負，calibration 真值卻是大的正值。
- 所以這是一階近似不足（大擾動的曲率損傷遠大於一階項），不是文本轉移問題。p8e1 的情況則 calibration 與新文章都能描述。

**選擇器**（calibration 上 argmin S_All，a bits ≤ 16，凍結後在新文章評估）

| 背景 | 選擇 | 與次佳的 margin | 新文章真值（相對 f16） | 集合內實測最好 |
|---|---|---|---|---|
| U | int8 | 0.101 | **+0.378**（128/128 篇都變差） | p8e1 |
| F | int8 | 0.058 | **+0.368** | p8e1 |
| W | int8 | 0.074 | **+0.379** | p8e1 |
| 原 BC（不隨背景） | f16 | — | 0（保守，錯過 p8e1 的收益） | — |

- 依規格判為：**局部機制有支持，但不能直接替代候選評分**。
- 單獨的 signed 一階分數會把大擾動、但一階項恰好為負的格式（int8）選成最佳，造成嚴重損傷。

### 4. 本輪支持與尚未支持的部分

| 主張 | 結論 |
|---|---|
| 條件化（依量化背景取梯度與擾動）有用 | **支持**（L27、p8e1）：F−U 與 W−U 的 position 0 背景效應方向都對，F−U 的量級幾乎相同；混搭分數顯示梯度與擾動都隨背景改變 |
| signed 一階項有用 | **支持**（小擾動）：正確預測 p8e1 在 position 0 有利、其他位置有害、整體有利；非負的 BC 做不到 |
| 只適用小擾動 | **支持**：int8、p6e1、p4e1 這類大擾動，在 calibration 就方向錯誤，選擇器因此選到嚴重有害的 int8 |
| 可直接當 selector／取代 BC | **不支持** |
| 跨層、native、與曲率項的組合 | **未測**（本輪依規格不做） |

**可能的下一步**（未執行，需另行設計）
- 只在小擾動或已通過曲率項門檻的候選上加入 signed 條件化項，例如保留 BC 的曲率項，再加上背景條件化的一階項。
- 跨層驗證需要處理後綴中的其他 QDQ（STE 或 surrogate）。

## 控制（全部通過）

**完整 forward 對照**
- closure loss 與「目標設為該格式的完整 forward」逐窗口相同：calibration 為 3 背景 × 9 格式，新文章為每個 chunk 的 f16，差都是 0。
- z 依完整 forward 的相同視窗批次計算；原因見揭露。

**重現前輪**：在 down_source 輪的文章上，U／F／W 的 f16 與 p8e1 逐位置 CE 與該輪 GPU 結果完全相同（差 0）。

**基準與梯度**
- f16 的 δz、S、D 都是 0。
- 位置 127 的梯度為 0。
- S_All = S_P0 + S_Rest（相對誤差 ≤ 8e-16）；以遮罩計算的真值與逐位置加總一致。

**背景與權重**
- 三個背景的目標權重都是同一份 INT8。
- W 只有 27 個前層 Down 權重量化、沒有 activation 量化；F 為 195 個投影的 w 與 a 都量化。

**環境**：TF32 關閉、deterministic。

**方向檢查**
- 在量化後的輸出空間做 α 插值，α = ±1 到 ±1/64，全部 grid 都保存在 `calibration_curves.csv`。
- 所有非零方向的 O/α 都在 α = 1/64 收斂到 S（容差 5% + 1e-3 summed CE），所以 g 本身是對的。大擾動的錯誤來自高階項，不是梯度數值錯誤。
- bf16 與 fp32 的方向極小，判為「未定」。
