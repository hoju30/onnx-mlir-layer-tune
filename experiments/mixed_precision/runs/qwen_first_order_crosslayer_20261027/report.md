# Qwen3 一階方向資訊的跨層確認（L7／L15／L23 Down）

日期：2026-10-27。程式：`run_qwen_first_order_crosslayer.py`。
規格：同日請求（`reports/` 中沒有對應的 prompt 檔）。
計畫：`plan.json`／`plan.md`，15:40:49 寫入，在任何新資料之前；本輪沒有 amendment。

**範圍**
- 事先指定的三個 Down 目標，權重都依 A：L7、L15、L23 都是 INT6。A 原本的 activation 為 p8e1／p6e1／p8e1，只作記錄；本輪一律以 f16 為基準。
- 兩個背景：U（其他投影 FP32）、F（其他投影依 A）。
- 候選：f16、p8e1、p6e1、p4e1、int8、int6、int4、bf16，input／output 同時換；fp32 只作控制。
- ranges 固定，沒有修改正式 BC、搜尋、MILP／knee 或 native。

**評分**
- 每個候選經真實的 block L+1..27（背景 QDQ 生效）、final norm 和 head。
- S = g_u·Δu：g_u 只經 head，u_0 為 detached leaf。
- K_full = K2_actual（輸出端二階參考，不是全模型 Hessian）。
- 主要比較是 K_full 對 S+K_full。S 單獨和校準實測 D_C 只作參考。

## 首頁：六個問題

**1. 一階是否改善同 bit 候選選擇？**

**沒有改善。依預先登記的規則，判讀為「變差」，但這只來自單一個選擇。**

- **主要效果**：δ = **+0.000102 nat/token [+0.000059, +0.000145]**，128 篇中 85 篇變差。它是 54 個同 bit 選擇（3 層 × 2 背景 × 3 校準組 × 3 bit）的平均後果，不是全模型 ΔNLL。
- 54 個選擇中，**K_full 全部選 Posit**。加入 S 後只改變了 **1 個**：
  - 條件：L15、U、校準組 1、int6 對 p6e1。
  - 改變內容：S+K 改選 int6；校準實測 D_C 在這一組也選 int6，但只差 0.00002。
  - 新文章：int6 比 p6e1 差 +0.0055 [+0.0032, +0.0078]。
- 其餘 53 個選擇完全相同，貢獻為 0。

**2. 修正幾對、破壞幾對？是否只是校準集變好？**

**是，只是校準集變好。** 28 對 × 18 個（層 × 背景 × 校準組）= 504 個配對判讀：

| 範圍 | 修正 | 破壞 | 都對 | 都錯／分數平手 | 真值未定 |
|---|---:|---:|---:|---:|---:|
| 校準集 C | **75** | 2 | 420 | 3／3 | 1 |
| 新文章 N | **0** | **22** | 377 | 0 | 105 |

- 75 個 C 修正到了 N 上：55 個未定、20 個破壞，**沒有一個成立**。
- 同 bit 配對（54 個判讀）：K 單獨在 N 上已經是 50 對、0 錯；加入 S 後多了 1 個破壞（就是第 1 題那個選擇）。
- 涉及 f16／bf16 的配對：C 修正 54 個，N 修正 0、破壞 10、未定 72。
- 原因：在這三層、兩個背景，新文章上**沒有任何量化格式被確認比 f16 好**（第 4 節）。所以「只有正負號項能修正」的那一類配對，在 N 上沒有東西可以修正。

**3. 效果是否跨層與校準組一致？**

一致地「沒有收益」：

- **主要 δ**：
  - L7、L23 都是 0（沒有任何選擇被改變）；L15 為 +0.00031（就是那一個選擇）。
  - 校準組 0、2 為 0；組 1 為 +0.00031。
  - bit：8 和 4 為 0；6 為 +0.00031。
- **配對層級**：每一層、每一組的 N 修正都是 0。破壞分布為 L7 F 10、L15 F 6、L23 U 4、L15 U 2；L7 U、L23 F 為 0。

**4. 已量化背景（F）是否比 FP32 背景（U）更需要一階？**

**不支持。**

- 依預先登記的規則，F − U 為 −0.000204 [−0.00029, −0.00012]，CI 排除 0。但這**完全是因為唯一被改變的選擇在 U**；F 的 27 個選擇沒有一個被改變。這不代表 F 需要一階。
- 配對層級反而是 F 的 N 破壞較多：F 16 個（L7 F 10、L15 F 6），U 6 個。
- 只限本輪條件。

**5. 哪些結論仍不成立？**

- 「加入一階能改善候選排序或選擇」：在三個新層上都沒有成立。
- 「已量化背景更需要一階」：不成立。
- L27 先前「p8e1 優於 f16、需要一階」的現象沒有在 L7／L15／L23 重現：這些層在新文章上沒有格式勝過 f16。
- 本輪不改變也不驗證正式 BC、其他層或完整搜尋。

**6. 是否值得下一輪研究低成本取得方向資訊？**

**目前不值得。沒有跨層證據支持加入一階。**

- 方向資訊在 C 上的「修正」全部無法轉移到新文章。
- S+K_full 與 C 實測非常接近：18/18 個情境的無限制 argmin 與 D_C 相同。
- 因此瓶頸是 10 個窗口的校準量測本身轉移不到新文字，不是方向近似。低成本近似只會複製同一個問題。

## 5. 配對與無限制 argmin（`pairwise_diagnostics.csv`、`argmin_outcomes.csv`）

各層／背景的 N 修正／破壞（28 對 × 3 組）：

| | U | F |
|---|---|---|
| L7 | 0／0（未定 21） | 0／**10**（未定 12） |
| L15 | 0／2（未定 24） | 0／6（未定 30） |
| L23 | 0／4（未定 6） | 0／0（未定 12） |

- C 修正最多的配對是 f16–p8e1（13）、f16–bf16（13）、p8e1–bf16（9）、f16–p6e1（7），都是「量化格式在 C 上看起來比 f16 好」。到了 N 上不是未定就是破壞。
- S 單獨的 N 判讀：60 對、339 錯、105 未定。

**無限制 argmin**（次要）
- K_full 必然選 f16（K ≥ 0、K(f16) = 0）。
- S+K_full 在 18/18 個情境與 D_C 選到同一格式。
- 新文章上沒有一個 S+K 的選擇被確認比 f16 好。被確認有害的有三個：L7 F 組 0 選 p4e1（+0.0144 [+0.0108, +0.0180]），L23 U 組 0／2 選 p8e1（+0.0005 [+0.0002, +0.0009]）。其餘未定。

**C 的近似精度**
- D_C − (S+K_full) 的最大絕對值：L7 0.009、L15 0.0017、L23 0.033。最大值都出現在高損傷格式（|D_C| 最大 0.16），排序沒有受影響。
- C 本身的雜訊很大。例如 L7 F 的 bf16，在三組 C 上是 −0.0064／−0.0071／−0.0037，在 N 上卻是 +0.0007（CI 跨 0）。p4e1 的單窗口 D 在 −0.045 到 +0.080 之間。這是 10 個窗口量測的轉移問題，不是評分近似。

## 7. 限制

- 只有三層、兩個背景、三組各 1280 tokens 的校準集。bootstrap 不含校準抽樣的不確定性，也沒有多重比較校正；配對結果只是描述。
- 主要判讀「變差」只建立在一個被改變的選擇上，不能推論成一階一般有害；比較穩妥的讀法是「沒有收益」。
- 新文章上沒有格式勝過 f16，所以本輪無法檢驗「當量化確實有益時，一階是否能抓到」。這正是 L27 F 的情況。
- K 單獨使用時必然選 f16，所以無限制 argmin 的結果只是次要。
- P0／Rest 只作機制觀察，沒有刪除或重新加權。
- L26／L27 只是歷史背景，沒有納入本輪統計。

## 8. 結論

在事先指定的 L7／L15／L23 Down、U／F 背景、三組 1280-token 校準集下：

- 加入一階**沒有改善同 bit 選擇**：54 個選擇只改變 1 個，而那個改變在新文章上有害。
- 28 對排序在校準集上修正 75、破壞 2，到了新文章上**修正 0、破壞 22**。
- 已量化背景沒有比 FP32 背景更需要一階。
- **結論：沒有跨層證據支持加入一階。**
- 依規格本輪到此停止：不改正式 BC、不重跑 MILP／knee、不建立啟用門檻、不挑層部署，也不追加實驗。
