# ResNet18：是否納入 input activation error 的消融

兩組都用相同權重 sensitivity，實際量化都包含 weight、input 與 output。唯一修改是 criterion 是否納入 input 誤差。

| 設定 | 內容 |
|---|---|
| 校準／held-out | 10／1,000 張 ImageNet-1K validation 子集 |
| FP32 top-1 | 70.6% |
| 求解器 | MILP，所有配置必須證明最優且符合預算 |
| W/A 候選 | int4–8、f16、bf16、fp32（各 8 種） |
| W＋O | 相對平方 weight 誤差＋相對平方 output 誤差 |
| W＋I＋O | shared_v2：再加相對平方 input 誤差 |

兩者共同乘上 S_i = mean(abs(W_i * dL/dW_i))。W＋O 僅在評分時省略 input；模型執行時 input QDQ 保持開啟。

## ORT 模擬

| f | W＋O top-1 | W＋I＋O top-1 | 加入 input 後差異（百分點） |
|---|---:|---:|---:|
| 0.60 | 19.0% | 21.3% | +2.3 |
| 0.65 | 55.7% | 56.5% | +0.8 |
| 0.70 | 65.0% | 65.6% | +0.6 |
| 0.75 | 65.9% | 68.1% | +2.2 |
| 0.80 | 69.1% | 69.1% | +0.0 |

## ONNX-MLIR 編譯後 QDQ

| f | W＋O top-1 | W＋I＋O top-1 | 加入 input 後差異（百分點） |
|---|---:|---:|---:|
| 0.60 | 18.9% | 20.9% | +2.0 |
| 0.65 | 55.0% | 56.0% | +1.0 |
| 0.70 | 63.8% | 64.8% | +1.0 |
| 0.75 | 66.5% | 67.8% | +1.3 |
| 0.80 | 69.4% | 68.7% | -0.7 |

完整 shared_v2 結果沿用同一模型、資料、敏感度與格式選單的前一輪實驗；重建的輸入／輸出誤差已與原始表核對。兩種後端分開比較。

相同的是資源上限，實際權重大小與 BOPs 用量可能不同。此為固定校準資料的單次比較，不代表加入 input 對所有模型或預算一定有利。
