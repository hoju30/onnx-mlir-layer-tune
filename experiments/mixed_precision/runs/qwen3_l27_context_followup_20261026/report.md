### 步驟 1：情境效應發生在哪個位置？——position 0

L27 Down 的 a 只在 position 0、或只在 1–127 改為 p8e1（x 與 y），其餘位置維持 f16：

| | 全 FP32 背景（U） | 全量化背景（F） | 情境改變（F − U） | Holm p |
|---|---|---|---|---|
| 只在 position 0 | −0.0057 [−0.0070, −0.0043] | **−0.0133** [−0.0149, −0.0117] | **−0.0076** [−0.0090, −0.0062] | < 1e-4 |
| 只在 1–127 | +0.0061 [+0.0049, +0.0073] | +0.0056 [+0.0042, +0.0070] | −0.0005 [−0.0021, +0.0011] | 0.53 |
| 全部位置 | +0.0004 | −0.0077 | −0.0082 | — |

**讀法**
- p8e1 在 position 0 本來就有利，在其他位置本來就有害。全 FP32 時兩者抵消，所以總效應約 0。
- 其他層量化後，**只有 position 0 的好處變大**（−0.0057 → −0.0133，110/128 篇方向一致）；其他位置的壞處幾乎不變。
- 位置效應精確可加（交互 = 0）。這符合結構：L27 之後只有逐位置運算，可當作控制。
- 附帶觀察：在原 knee 的背景下，「只在 position 0 用 p8e1、其他位置維持 f16」得到 −0.0133，比全部位置用 p8e1（−0.0077）還好。目前的 pipeline 不支援依位置選格式，這只是描述。

### 步驟 2：FFN 中是哪些投影？——前面各層的 Down 投影

相對 U 的變化（D_g − D_U，4 組 Holm 校正）：

| 子組（只有這些投影依 A 量化，其餘 FP32） | 投影數 | D_g − D_U [95% CI] | Holm p |
|---|---|---|---|
| **ffn_down：L0–26 的 down_proj** | 27 | **−0.0042** [−0.0057, −0.0028] | **< 1e-4** |
| ffn_gu：L0–26 的 gate + up | 54 | −0.0009 [−0.0027, +0.0010] | 0.36 |
| ffn_early：L0–13 的 FFN | 42 | −0.0015 [−0.0031, +0.0000] | 0.16 |
| ffn_late：L14–26 的 FFN | 39 | −0.0018 [−0.0037, +0.0001] | 0.16 |

**加成性**
- 依深度切：完整 FFN 等於前半加後半，殘差 −0.0000 [−0.0020, +0.0019]。前後半各占約一半，沒有交互。
- 依類型切：完整 FFN 減去（gate/up + down），殘差 +0.0018 [−0.0004, +0.0039]，不顯著。只量化 Down 的效果甚至略大於整個 FFN。

**結論**
- 在 FFN 中，造成 L27 情境效應的是前面各層的 Down 投影。
- 這個效應分散在各層深度，不是集中在某一層。

## 整體圖像（兩輪合併）

- **哪裡**：效應完全發生在 L27 Down 的 position 0。
- **誰造成**：主要是前面各層的 Down 投影被量化。上一輪顯示 L27 自己的其他投影與 FFN 之外的部分也有交互貢獻，attention 單獨量化則沒有效果。
- **為什麼（線索，未證明）**
  - Down 投影的輸出直接寫進 residual stream。L2 Down 正是 position 0 massive activation 的產生處，前面各輪已看到它的 output 超過 6000。
  - 前面各層 Down 的量化誤差會改變 position 0 的 residual；L27 在 position 0 的 p8e1 量化剛好抵銷了一部分，形成「誤差補償」。
  - 本輪沒有拆分前面 Down 的權重或 activation、input 或 output，所以補償的具體路徑仍未定。

**對 pipeline 的意義**
- 這是「量化誤差在 position 0 跨層累積，再被另一層的量化部分抵銷」的交互效應。
- 單節點、FP32 背景、可加的 BC 在結構上看不到它，這解釋了為何自動搜尋找不到 L27 的收益。

## 控制（全部通過）

- **重現前輪**：在 L27 native confirm 的文章上，F + f16、F + p8e1 與前輪 PyTorch A／C 逐位元相同。
- **hook 路徑**：位置遮罩設為 "all" 時，與 LMReplay 原路徑逐位元相同。
- **背景定義**：U 背景且目標 (w, a) 皆 fp32 時，與全 FP32 模型逐位元相同；各背景量化投影數與計畫相同（F 195、ffn 81、early 42、late 39、gate+up 54、down 27）。
- **環境**：TF32 關閉、deterministic。
- **結構驗證**：position 0 與其餘位置的效應精確可加（交互 = 0）。
