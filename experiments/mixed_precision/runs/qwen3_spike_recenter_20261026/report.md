### 1. 新 μ_N 是否讓 L2 Posit 的一般 token 平均項／剩餘項減少？哪些分項改變？

**Posit**
- 全域 μ 被 position-0 spike 的截斷誤差帶歪，在一般 token 上產生假的平均項 U 與假的剩餘項 V_N。
- 改用 μ_N 後，這兩項幾乎歸零。
- spike 行的分項（V_S 或 P_S）幾乎不變。

**INT**
- INT 的 range 被 spike 撐到 [−3012, 3787]，一般 token 全部量化成 0。
- 因此 int4／6／8 在一般 token 上的誤差完全相同，V_N(μ_N) 都是 976.9；μ_N 對 INT 幾乎沒有影響。

**L27**
- μ 本來就不是由 spike 行主導：p4e1 的 U 1367 → 1376、V_N 227 → 218。
- L27 的分數與選擇因此沒有改變。

**反例：L2 4-bit**
- p4e1 的 V_N(μ_N) = 180 小於 int4 的 977，所以 D 改選 p4e1。
- 實測卻是 p4e1 遠比 int4 傷：新文章 ΔNLL 3.82 對 0.29。

### 3. 相對舊分組／舊配對，改善來自哪個固定修改？還有哪些無法區分？

**選擇的改變（修正與新增誤排）全部來自新分解，與 spike 的同位置配對無關。**

| 比較（新文章，Holm 家族 6 個） | 平均 ΔR [95% CI] | 不同選擇數 | Holm p |
|---|---|---|---|
| G01 − G00（固定全域分解，只改 spike 配對） | 0 [0, 0] | 0 | 1 |
| D − G10（固定新分解，只改 spike 配對） | 0 [0, 0] | 0 | 1 |
| G10 − G00（固定 spike 用組平均 g²，換成新分解） | +0.0362 [+0.0353, +0.0372] | 3（L2 全部） | < 1e-4 |
| D − G01（固定 spike 同位置配對，換成新分解） | +0.0362 [+0.0353, +0.0372] | 3 | < 1e-4 |
| G00 − A（舊分組） | 0 [0, 0] | 0 | 1 |
| P − A（舊全元素配對） | **−9.0e-5** [−1.15e-4, −6.0e-5] | 1（L27 int8–p8e1） | < 1e-4 |

- 舊分組（G00）已經把 L2 Posit 的 V_all 放大從約 1e6 降到約 1e4，但選擇仍與 A 相同。翻轉需要新分解；新分解又必然同時翻轉三個 L2 配對。
- p 值的解析度受 bootstrap 次數限制（10000 次），「< 1e-4」表示所有重抽都落在同一側。

**無法區分的因素**
- 「新分解」同時做了三件事：spike 不進 μ_N、U 只用 N 行的梯度和、spike 改用未中心化的 e 評分。
- 本輪的 2×2 設計無法把它們分開。

**為何 L2 4-bit 會錯（只是線索，未證明）**
- p4e1 的 maxpos 只有 16，會把約 3000 的 spike 削到 16。
- 前輪診斷在原 calibration 上量到：p4e1 只動 position 0 的 r-only 損傷是 2.93 nat/token，局部曲率卻只有 0.146。
- 所以 spike 被削掉的真實損傷是強烈的有限幅度效應，任何局部的 Σg²e² 都看不到。
- D 移除全域 μ 的假象後，p4e1 只剩下被低估的 spike 項（674）與較小的一般 token 項（180），總分因此低於 int4。

**附帶結果（次要，不取代 D）**
- 舊全元素配對 P 在這批新文章上修正了 L27 int8–p8e1，經確認，P − A = −9e-5 nat/token，Holm p < 1e-4。
- 它在 20261023 那批文章上未定（−2.7e-5，CI 跨 0）。
- 效果極小，且 P 早已在先前測過，本輪不把它視為新候選。
